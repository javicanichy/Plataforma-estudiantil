Especificaciones Técnicas

Stack Tecnológico
Python 3.9.3 Flask (Microframework) SQLAlchemy (ORM) PostgreSQL Jinja2 Engine Bootstrap 5.3 JavaScript (ES6+)
Mecanismos y Seguridad
  • Autenticación: Flask-Login y gestión de sesiones.
  • Cifrado: Hashing PBKDF2 con Werkzeug Security.
  • Seguridad: Protección CSRF y saneamiento de inputs.
  • Arquitectura: Patrón MVC (Modelo-Vista-Controlador).
Filosofía de Desarrollo

Este sistema ha sido desarrollado bajo principios de Mobile-First y Clean Code. Se ha priorizado la eficiencia en las consultas relacionales y la seguridad del usuario, garantizando una plataforma robusta para la comunidad universitaria de la UNGE.
